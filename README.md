# MedicalDataAnalysis
 Data Overview
The dataset contains the following columns:
age – Patient age
gender – 1 (Male), 0 (Female)
heart rate – Beats per minute
systolic/diastolic blood pressure – Measured in mmHg
blood sugar – 1 (>120 mg/dL), 0 (Normal)
CK-MB & Troponin – Medical indicators
output – 1 (Heart Attack), 0 (No Heart Attack)

Analysis Breakdown
1️⃣ Load & Explore Data

2️⃣ Perform Basic Data Analysis
